## Evidence and implementation map

- `data/exam.py`, `scripts/run_stage2.py data`: rehash the pinned Stage 1 CMExam train/val source; consume the already sealed Stage 1 question-only cluster graph (including heldout exclusions), without reopening test labels. Validate all 54,497 train rows. Freeze one deterministic representative per clean cluster, seed42, then 15k pool and independently ordered 1k formal IDs. Smoke uses 50 other pool IDs. Freeze 512 monitor /1024 selection validation IDs at cluster boundaries, remainder diagnostic reserve. Source answers/explanations remain side channels.
- `reward/parser.py`: explicit ParseResult, one closed answer block; fallback only in final region after closed thinking or explicit final response without thinking; reject ambiguity, duplicate letters, illegal choices, malformed tags and trailing conflicting conclusions. Exact canonical set correctness and format following remain separate. Preserve Stage 0 parser for its historical tests.
- `reward/semantic.py`, semantic diagnostic: compare fixed local MedEmbed-small and BGE-M3 on 200 controlled pairs spanning the requested 15 categories, with train-only provenance or explicit synthetic perturbations. Stable cosine clip; no batch scaling. Non-overlapping <=480 encoder-token chunks, length-weighted normalized embeddings, no silent truncation. Record lengths, chunk boundaries, latency, memory, ranking and failures. Decide encoder before smoke reward freeze, retaining the baseline 0.8/0.15/0.05 formula and correctness gate unless explicit decision says otherwise.
- `rollout/profile.py`: fixed Stage 1 manifest adapter and BF16 Qwen revision, vLLM0.24 V1/native sampler/batch-invariant/split_k1, TP1, eager, max_num_seqs16, context4096, memory0.65, prefix cache off. Same-runtime positive/negative adapter controls and sleep/wake parity without actor updates. Initial cap1024, temperature0.6/top_p1/top_k-1. Native Qwen template supplies only question/options/format instruction.
- 50×4 smoke, then train-only longer-cap diagnostic only if truncation>5% or closure<95%; diversity diagnostic only if near-collapse warrants it. Freeze policy/sampling/parser/reward/encoder hashes before independent 1k×4 FORMAL run.
- Raw generation written durably before reward/aggregation; bounded request batches and atomic complete-group records. Same-run recovery consumes only missing frozen IDs with deterministic per-prompt seeds. Completed means stop/length, not missing/exception. Identical sampled text is valid diversity evidence when distinct request/member lineage exists; duplicate trajectory IDs are invalid. Attempt WAL retains retries, failed costs or explicitly UNKNOWN tails.
- `reward/hybrid.py` returns score/acc/sem/format/parse_status dict compatible with installed verl reward manager. Score all responses (including wrong) for diagnostic raw semantic; correctness gate makes wrong contribution zero. Sequential GPU embedding after vLLM process exits avoids co-residency; frozen reward applies to retained raw data, no policy update.
- `analysis/stage2.py`: exact raw group classification and 0–4 histogram, pass@4, accuracy, lengths and parse/semantic slices, exposure, all costs, cases. Review >=50 complete raw trajectories as manual qualitative review, not clinical adjudication or external LLM scoring.
- `scripts/verify_stage.py --stage 2`: recompute raw counts/lineage, parsing/reward/group summaries, hashes, tests, diagnostics/cases/review/report, policy unchanged and zero updates. Retrospective report, interview material, resume ledger, actual compute calibration, state transitions, commit/push main and clean working tree complete this stage.

Git keeps compact results; raw texts/token IDs/embeddings/logs in `/data/WSH/medical-post-train-artifacts/runs/<run_id>`. No overwrite of previous failed/invalid run. Source-only semantic/download failures are retained too.
